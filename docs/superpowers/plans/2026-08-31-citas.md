# Gestión de Citas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar el módulo completo de citas sobre el modelo existente, con disponibilidad real, estados, seguridad, filtros y persistencia histórica de precio y duración.

**Architecture:** `CitaController` delega en `CitaGestionService`, que coordina validadores de catálogo, disponibilidad base, solapamientos y estados. Los repositories resuelven locking, filtros y cargas batch en PostgreSQL; `CitaMapper` construye DTOs sin consultas.

**Tech Stack:** Java 21, Spring Boot 4.1, Spring Data JPA, Specifications, Bean Validation, Spring Security, JUnit 5, Mockito, MockMvc y Testcontainers PostgreSQL.

## Global Constraints

- Trabajar exclusivamente en `feature/citas`.
- No hacer commit, push, merge, rebase ni cambio de rama.
- No modificar entidades, esquema, SQL, migraciones ni `pom.xml`.
- No implementar atención, peluquería, pagos, comprobantes, reportes o notificaciones.
- Aplicar TDD y usar fechas relativas con segundos/nanos normalizados.
- Reutilizar `DisponibilidadTrabajadorService` y `PaginaResponse<T>`.
- No aceptar precio, duración, tipo, fin, cliente o registrador desde frontend.
