# Vacunas y Vacunas Aplicadas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar el catálogo de vacunas y el registro clínico inmutable de vacunas aplicadas con autorización, paginación PostgreSQL y pruebas completas.

**Architecture:** Mantener la arquitectura modular existente. El catálogo tendrá controller, service, repository, mapper y DTOs propios. Las aplicaciones se registrarán bajo `AtencionMedica`, con autorización de autoría clínica en el service y consultas históricas optimizadas.

**Tech Stack:** Java 21, Spring Boot 4.1, Spring Data JPA, PostgreSQL, Spring Security JWT, Bean Validation, Mockito, MockMvc y Testcontainers.

## Global Constraints

- Trabajar únicamente sobre `main`.
- No commit, push, merge, rebase ni cambio de rama.
- No modificar tablas, columnas, índices, constraints, migraciones, entidades existentes ni `pom.xml`.
- No implementar DELETE ni edición de `VacunaAplicada`.
- No usar H2.
- Usar `PaginaResponse<T>` para el historial de mascotas.
- Ejecutar `docker version`, `./mvnw.cmd clean test` y `./mvnw.cmd clean verify` antes de reportar resultados.
